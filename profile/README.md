# PromptMentions

**AI visibility tracking for agencies serving B2B SaaS companies.**

[PromptMentions](https://promptmentions.com) records how ChatGPT, Perplexity and Claude answer the questions buyers ask, keeps every answer as evidence, and turns what it finds into tasks, reviewed content and client reports.

- **Evidence behind every number:** each figure links to the full recorded AI answer, labelled with provider, model, prompt, locale, time and sample size.
- **Competitors and cited sources:** see which sources AI answers cite and where competitors appear instead of your client.
- **From finding to fix:** tasks, source-backed briefs and drafts, published only after a person approves them, with WordPress delivery as a draft.
- **Client reports:** printable, shareable reports for any date range, plus a read-only API and MCP access.
- **One workspace, a project per client.**
